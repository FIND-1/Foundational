# 阶段复习与跨章节综合实践

本目录存放主线课程的**阶段复习材料**，与正式课程章节目录（`01-*` ～ `15-*`）保持分离。

## 复习原则

1. **按 3～5 章触发**：每完成 3～5 章，按知识关联安排一次跨章节综合实践，避免学完即忘或机械刷题。
2. **三大重心**：聚焦**知识回忆**（不翻书复述核心心智模型）、**代码应用**（跨章组合写出可运行的小任务）、**错题复盘**（结合已有 `notes.md` 第 4 节和速览章的理解检查复盘易错点）。
3. **不重复考旧章**：阶段复习不是重考已结课章节；不针对已通过验收的单章重复出考试卷。
4. **单章人工测验边界**：
   - `pytest` 自动化测试与人工测验分开管理，不强制每章生成人工测验。
   - 如某章确需人工问答/测验，**单章最多两轮**，首轮达标即可提前结束。
5. **按需创建，不提前占位**：只有当对应区间的最后一章完成验收后，才在本目录下创建该次阶段复习子目录（命名约定：`rNN-<topic>/`，如 `r01-basics-and-types/`）。

## 每次阶段复习的标准结构（触发时再建）

进入某次阶段复习（如 `r01-<topic>/`）时，仅创建实际需要的轻量文件：

- `README.md`：本次复习的 3～5 个核心回忆问题、错题复盘清单（指向原章 `notes.md`）与综合小任务说明。
- `practice_rNN.py`（可选）：一个跨章节的综合应用小程序（不按单章切片出填空题）。
- `test_practice_rNN.py`（可选）：仅在需要自动校验综合任务边界用例时创建。
